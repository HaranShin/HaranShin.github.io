# 발화 패턴 분류 1													
												
1. 단답 단어형
+ *고객이 봇에 익숙하지 않거나 거부감이 있을 때, 또는 메뉴 선택형 IVR 경험이 강할 때 나타남
+ **예시**: “네” / “아니요” / “1번” / “확인” / “됩니다”
+ **대응**: 단답도 처리 가능한 인텐트 등록 + 추가 확인 질문으로 보완 발화 유도
2. 복합의도형
+ 고객이 하고 싶은 말을 한번에 다 쏟아내는 유형. NLU가 첫 번째 의도만 잡거나 혼란스러워 실패하는 케이스가 많음
+ **예시**: “요금 조회하고 싶고요, 혹시 납부도 지금 바로 할 수 있나요?”
+ **대응**: 멀티 인텐트 처리 로직 추가 / 봇이 먼저 하나씩 확인하도록 대화 분기
3. 감정발화 / 봇 거부형
+ 반복 실패나 누적 불만으로 감정이 발화에 실려 나오는 유형
+ **예시**: “아 그게 아니라고요” / “상담원 바꿔줘요” / “도대체 몇 번을 말해야 해”
+ **대응**: 즉시 공감 응답 + 일정 횟수 이상이면 자동 에스컬레이션
4. 침묵 / 비응답형
+ 질문을 이해 못 했거나, 봇에 말 걸기가 어색하거나, 환경 소음으로 발화가 막힌 케이스.
+ **예시**: [침묵 3초] / [배경소음만] / “…”
+ **대응**: 단순 재촉보다 질문 방식 자체를 바꿔야 함. 재질문 시 다른 표현으로 바꾸고 선택지 제시 / 2회 실패 시 에스컬레이션
5. 범위 이탈형
+ 봇이 다룰 수 없는 주제나 엉뚱한 질문. 이탈이 많은 인텐트 중 이 유형이 상당 비율 차지. 어떤 주제가 자주 빠지는지 파악하면 다음 기능 확장 방향이 나옴
+ **예시**: “이 제품 어떻게 쓰는 거예요?” / “다른 통신사로 바꾸고 싶어요”
+ **대응**: “해당 내용은 제가 도와드리기 어렵지만 ○○으로 안내해 드릴게요” 처리 + FAQ 확장 검토											
													
# 발화 패턴 분류 2		

1. 발화길이

| 유형 | 구조 | 예시 |
|---|---|---|
| 단어형 | 단어 1개 | "취소" / "확인" / "환불" / "응" |
| 구형 | 단어 2~4개, 주술 구조 없음 | "요금 조회요" / "다음 달로" / "카드 납부" / "뒤로 가기" / "이전 단계" |
| 문장형 | 주어+서술어 완전한 문장 | "요금을 다음 달로 미루고 싶어요" / "주문한 거 아직도 안 왔는데 어떻게 해요" |



2. 의도 명확성
+ 명확
+ 모호 (“그거 좀요”)
+ 복합 (“환불도 하고 주소도 바꾸고 싶어요”)
3. 감정 톤
+ 중립
+ 불만 (“왜 이렇게 느려요”)
+ 긴급 (“지금 당장”)
4. 대화 전략
+ 명령형 (“연결해줘”)
+ 질문형 (“되나요?”)
+ 설명형 (상황을 길게 서술)
5. 오류 유발
+ 방언
+ 외래어 혼용
+ 배경소음
+ 말 끊김

## 우선순위
우선순위 = 발생 빈도 × 이탈 기여도 × 수정 난이도(역수)
