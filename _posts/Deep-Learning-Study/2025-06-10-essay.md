# 연구목적	
에어컨, 세탁기, 냉장고, 김치냉장고, 식기세척기, 오븐레인지 6개 백색가전에 적용할 최적의 음성 사용자 인터페이스(VUI) 가이드라인 개발

# 연구 방법
주부 4명 대상 사전 FGI(포커스 그룹 인터뷰) → 프로토타입 제작 (Macromedia Flash) → 주부 34명 대상 5개 세션 실험 진행

# 주요 실험 결과

## 🔊 음성의 물리적 특성

* 성별 => 여성 목소리가 더 선호됨 (남성은 낮설고 어색하다는 반응)
* 음높이 => 통 수준의 음높이를 지닌 여성의 음성이 상대적으로 더 높은 평가 (안정감·신뢰감)
* 억양 => 일반적인 억양으로 안정되고 편안함을 표현하되 너무 사무적이지 않도록 유의하는 것이 중요


## 🗣️ 음성의 어투 (합쇼체 vs. 해요체)

| 상황 | 권장 어투 | 특징 / 설명 | 주의사항 |
|---|---|---|---|
| 일반 조작 멘트 | 합쇼체 | 정중하고 신뢰감 있음. 사용자가 익숙하게 받아들임. | |
| 경고/알림 멘트 | 합쇼체 | 간결한 느낌을 주며 귀에 더 잘 들어온다 | 마치 명령을 받는 느낌이 들어 합쇼체를 비선호도 있었음.<br>부정적인 정서를 유발할 수 있어서 어투를 선택할 때에도 이를 고려하여 설계 |
| 알림 멘트 중 요구성 멘트 | 해요체 | 부드러운 느낌을 주고, 듣기에 좋으며, 딱딱하고 짜증이 나지 않게 말해주기 때문에 더 적합. 당장 행동을 취하지 않아도 되는 덜 중요한 멘트이므로 더 부드럽게 말해주는 것이 좋다 | |

※ 경고 멘트에 한해서 음성과 함께 소리가 제시 & 음석의 속도를 빠르고 톤을 높여서 주의를 더 환기시키고 긴박한 느낌을 주어야 한다는 의견이 있었다

* 대부분의 사용자들은 해요체가 너무 친숙한 느낌을 주어 듣기 “거북스럽고”, “방정맞고”, “가볍다”는 생각이 들어 비선호되고 적절하지 못하다고 생각


# 음성표현의 간결성
* 빈번한 조작 시 => 핵심 내용만 짧게 말하는 것이 선호됨
* 단순 청각신호(비프음)만으로는 의미 전달이 부족하고 부정적 인식 위험 있음.
* 고연령층은 긴 음성 표현도 수용하는 경향
	
# 경고·알림 음성 메시지
* 신호음 + 음성 결합 방식이 가장 선호되고 반응시간도 가장 빠름
* 음성만 있으면 주변 소음에 묻힐 수 있어, 신호음으로 주의를 먼저 끈 뒤 음성으로 의미 전달하는 방식이 최적
* 신호음만 있는 기존 방식은 가장 낮은 평가

# 결론 (가이드라인 핵심)
보통 톤의 여성 목소리 + 합쇼체 + 간결한 표현 + 신호음·음성 결합 피드백이 가전제품 VUI에 가장 적합하며, 이 결과는 실제 LG전자 제품 개발에 반영되었음.
