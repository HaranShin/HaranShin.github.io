# 목적
내 컴퓨터에 Jekyll 환경을 세팅하면, VS Code 터미널에서 명령어 한 줄로 실제 깃허브 블로그와 100% 동일한 화면을 로컬에서 실시간으로 띄워볼 수 있다.												
													
## 1.jekyll bundler 설치 		

* VS Code 터미널 열기 (Ctrl + ~)

```bash
gem install jekyll bundler
bundle install
```



## 2.Gemfile 파일 열기 및 코드 추가
ctrl+p를 눌러 **Gemfile (확장자 없음) 파일**을 열고, 맨 아래에 다음 두 줄을 복사해서 붙여넣고 저장(Ctrl + S).
```bash
gem "tzinfo", "~> 2.0"
gem "tzinfo-data", platforms: [:mingw, :mswin, :x64_mingw, :jruby]
```

*로컬 서버 실행

```bash
bundle exec jekyll serve
```


## 3.실행하기
터미널에 나오는 [http://127.0.0.1:4000](http://127.0.0.1:4000) 주소를 브라우저에 입력하여 접속합니다. 코드를 수정하고 저장하면 브라우저에 바로 반영.
